# Contributing to Visual World Model Explorer

Thank you for your interest in contributing! We welcome contributions to add new model backends, improve visualizations, fix equations sandbox math, and update documentation.

## How to Contribute

1. **Submit Issues:** Report bugs or request features.
2. **Pull Requests:** 
   - Fork the repository.
   - Implement your change (e.g., adding a new backend under `backends/`).
   - Run verification tests.
   - Open a PR describing your edits.

## Adding a New Backend Plugin

Refer to `pages/19_About.py` or the `examples/load_custom_backend.py` file for architectural instructions on implementing the `BaseModelBackend` interface.
